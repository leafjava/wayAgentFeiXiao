# TokenTruth 项目描述

## 一句话介绍

TokenTruth 是一个面向代币投资者、RWA 发行方和合规团队的证据型项目研究平台，帮助用户弄清楚一个代币到底代表什么、依据是什么、风险在哪里，以及之后能否验证。

## 项目背景

代币项目的白皮书、代币规则、市场数据、解锁计划、项目公告和风险提示通常分散在不同网站、社交媒体和文档中。用户很容易只看到价格和营销文案，却不了解代币的真实权利、底层资产、赎回条件、转让限制、发行计划和潜在风险。

RWA 项目进一步增加了托管方、监管框架、KYC、地区限制、NAV、审计和分红等复杂信息。普通用户很难判断一个代币代表真实资产、真实股权，还是只代表项目方定义的使用权。

TokenTruth 将这些资料整理成结构化、可追溯的知识库，让投资者、项目方和合规人员使用同一套事实和证据进行沟通。

## 我们解决什么问题

- 项目资料分散，用户很难快速找到原始依据；
- 代币权利描述不清，股权、收益权、赎回权和使用权容易混淆；
- 项目方更新规则后，旧版本和变化过程不容易追踪；
- 市场价格变化与项目基本面、解锁和风险之间缺少解释；
- RWA 资产的 KYC、地区资格和合规要求容易被普通加密交易逻辑忽略；
- 投资者需要提醒和模拟执行，但不应该把 AI 直接变成未经授权的自动交易机器人。

## 核心解决方案

TokenTruth 建立一个以证据为中心的项目知识库。系统收集并整理白皮书、产品说明、代币规则、市场快照、解锁公告、风险提示和项目方更新，然后通过结构化问答和多维分析帮助用户理解项目。

重要资料版本、风险变化、投资者问答和购买前授权可以生成内容哈希，并在 Monad Testnet 上进行存证。链上记录用于证明某份资料或操作记录在某个时间点已经存在且之后没有被悄悄替换，不用于替代审计、监管或法律判断。

## 目标用户

### 投资者和研究者

用户可以直接询问：

- 这个项目靠什么产生价值？
- 我购买的代币有什么权利？
- 它是否代表真实股权或底层资产？
- 是否有分红、赎回和转让权？
- 购买需要什么资格？
- 当前最大的风险和潜在解锁压力是什么？

### RWA 发行方

发行方可以维护项目资料、生成版本差异、编写公告和风险说明，并用证据哈希证明披露内容和发布时间。

### 合规平台和风控人员

平台可以查看底层资产、托管方、监管框架、KYC、地区限制、赎回、分红和转让字段，并根据资产类别执行不同流程。

## 核心功能

### 1. 有来源的 AI 问答

`/chat` 根据项目资料回答商业模式、代币权利、转让、赎回、分红、托管、解锁和风险问题。回答带有引用、来源和可信度；资料没有披露时，系统会明确标记“未披露”。

### 2. 多维项目分析

`/analyze` 从基本面、市场、资料/社区和风险四个维度分析项目。RWA 项目还会展示底层资产、托管、监管、KYC、赎回、NAV 和审计信息。

### 3. 项目资料和版本管理

`/projects` 和项目详情页展示项目、文档、来源和风险状态。项目方可以编辑资料，系统保留旧版本并生成差异，避免只保留最新内容。

### 4. 跟踪和模拟执行

`/track` 支持关注列表、投资计划、价格和风险跟踪。购买、赎回和分红流程默认是 Mock 模式，也可以使用 Monad Testnet 演示钱包签名和链上状态查询。

### 5. 链上证据存证

系统对披露、风险变化、问答、授权和执行记录生成哈希。链上只保存哈希和必要元数据，不保存私钥、身份证或完整敏感内容。

## Demo 资产：Pax Gold（PAXG）

第一版使用 Paxos 发行的 PAX Gold 作为 RWA 案例。PAXG 每枚代表一金衡盎司的 London Good Delivery 黄金，适合演示底层资产、托管、赎回、转让和市场价格之间的关系。

PAXG 不代表 Paxos 股权，也不提供分红权。直接铸造和赎回需要符合 Paxos 的账户、KYC、地区和费用要求；二级市场交易还要遵守交易平台规则。

## 合规和安全边界

TokenTruth 不是交易所、券商、托管方或投资顾问：

- 不托管用户资金；
- 不收集私钥和助记词；
- 不绕过 KYC、AML 或地区限制；
- 不自动替用户买卖资产；
- 不承诺收益，也不提供个性化投资建议；
- 真实 RWA 交易必须通过具备资质的发行方、券商或托管方；
- Mock 和 Monad Testnet 交易不代表真实资产所有权。

项目不是专门的“反老鼠仓”执法系统，但可以通过记录解锁、公告、版本变化、风险状态和授权证据，帮助用户发现信息不对称、潜在抛压和披露变化。

## 技术架构

TokenTruth2 使用与 Orchor 类似的 Next.js 全栈单体架构：

- Next.js 14 App Router：页面和 Serverless API 统一部署；
- React + TypeScript：构建交互式研究和项目管理界面；
- Prisma + SQLite：本地 Demo 数据持久化；
- DeepSeek：可选的来源型问答增强层；
- viem：Ethereum/Monad Testnet 钱包和链上交互；
- Solidity：Disclosure Registry 证据存证合约；
- Vercel：单项目部署前端页面和 API Route Handlers。

## 演示流程

1. 打开项目目录并选择 PAXG；
2. 查看底层黄金、Paxos、赎回和转让规则；
3. 在问答页询问“PAXG 是否代表 Paxos 股权？”；
4. 在分析页查看市场数据、资料来源和风险；
5. 在跟踪页创建模拟购买计划；
6. 确认 KYC、地区和风险要求；
7. 生成模拟订单和证据哈希；
8. 在区块浏览器中验证 PAXG 合约或 Monad Testnet 存证记录。

## 项目价值

TokenTruth 不试图告诉用户“应该买什么”，而是先把“买到的是什么、依据是什么、风险在哪里、能否验证”讲清楚。

它把投资者问答、项目资料、RWA 合规字段、市场解释、版本管理、模拟执行和链上存证放入同一条工作流，降低研究、沟通和审查成本，并为未来接入更多真实资产、持牌平台和实时数据提供基础。
